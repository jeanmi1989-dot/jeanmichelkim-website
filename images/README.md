# 画像について

## 現在使用中の写真（Jean-Baptiste Millot撮影）

2026年8月、いただいた7枚のプロ写真をWeb用に軽量化して配置済みです（元は10〜17MBのため、
表示速度のために縮小・圧縮しています）。元の高解像度ファイルは `images/_originals/` に
そのまま保管してあります（印刷用途やプレスキットで高解像度が必要な場合はそちらを使用）。

| ファイル | 内容 | 使用箇所 |
|---|---|---|
| `hero.jpg` | 横顔のシルエット、ドラマチックな片側照明 | トップページ背景 |
| `portrait-home.jpg` | 鍵盤に置かれた両手のクローズアップ | トップページ紹介セクション |
| `portrait-bio.jpg` | 大理石装飾を背にした立ち姿 | プロフィールページ |
| `gallery/photo-1.jpg` | ピアノと青いカーテンを背景に微笑む表情 | ギャラリー |
| `gallery/photo-2.jpg` | 黒背景の全身ショット | ギャラリー |
| `gallery/photo-3.jpg` | 赤い椅子・横顔の室内ポートレート | ギャラリー |
| `gallery/photo-4.jpg` | 顔のクローズアップ | ギャラリー |

差し替えたい場合は、同じファイル名で上書きするだけで反映されます。

## 動画にする場合（任意）

`images/hero.mp4` を用意し、`index.html` 内のコメントの指示に従って
`<img>` をコメントアウト → `<video>` ブロックのコメントを外してください。
（詳しい仕様は `../HIGGSFIELD_GUIDE.md` を参照）
